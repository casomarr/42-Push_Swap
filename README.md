# Push_Swap

## Goal

Sort a stack of integers using a limited set of operations and two auxiliary stacks. The project focuses on algorithmic efficiency and optimization.

## Key Features

- Stacks: Use two stacks (A and B) to manage and sort numbers.
- Operations: Perform specific operations like swap, push, and rotate to rearrange the stack.
- Sorting Algorithm: Implement an efficient algorithm to minimize the number of operations.
- Checker Program: Verify the correctness of the sorting sequence produced by the main program.

## Allowed Operations:

- Swap: Swap the top two elements of a stack.
- Push: Move the top element from one stack to another.
- Rotate: Shift all elements of a stack up or down by one position.

## Challenges

- Optimization: Minimizing the number of operations to achieve sorting.
- Large Inputs: Handling large stacks efficiently without excessive runtime.
- Edge Cases: Managing inputs with duplicate values or invalid formats.

## Skills Developed

- Algorithm Design: Crafting efficient sorting strategies for constrained environments.
- Data Structures: Managing and manipulating stacks effectively.
- Optimization: Balancing time and resource efficiency in algorithmic solutions.

## Installation

1. Clone the repository:
```sh
git clone git@github.com:casomarr/42-Push_Swap.git
``` 

Navigate to the project directory:
```sh
cd push_swap  
``` 
Compile the program:
```sh
make  
``` 
Run the program with a list of integers:
```sh
./push_swap <list_of_integers>  
``` 
Example:
```sh
./push_swap 3 1 2 4 0  
```
